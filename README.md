# Hevine Salloum · Front-End Portfolio

1. Extract the ZIP.
2. Upload the extracted contents to the root of your GitHub repository. Keep `index.html` and the `projects/` folder together.
3. Open **Settings → Pages**, choose **Deploy from a branch**, then select your default branch and **/ (root)**. Save and open the URL shown by GitHub Pages once deployment finishes.

The contact link opens the visitor's email app. The bakery checkout previews sample orders. Weather, exchange rates, map tiles, and external styles and images require an internet connection.
